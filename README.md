## 📝 Sobre

O **Windows 10 / 11 Optimizer** é uma ferramenta avançada para otimização do sistema operacional Windows, projetada estrategicamente para maximizar o desempenho, reduzir o tempo de inicialização, otimizar recursos de hardware e aprimorar significativamente a experiência do usuário.

---

## 🛠️ Recursos

* **🔍 Diagnóstico Inteligente em Tempo Real:** Análise instantânea de gargalos e serviços desnecessários.
* **🎯 Perfis de Desempenho Personalizáveis:** Escolha ou personalize o perfil ideal para o seu uso (Jogos, Trabalho, etc.).
* **🧹 Limpeza Profunda do Sistema:** Remoção avançada de arquivos temporários, caches persistentes e bloatwares.
* **🌐 Otimizações de Rede:** Ajustes no stack TCP/IP para redução de latência e estabilização de ping.
* **🔒 Privacidade Reforçada:** Desativação segura de telemetrias pesadas e rastreadores de segundo plano.
* **🛡️ Modo Seguro de Reversão:** Criação automática de pontos de restauração antes de qualquer modificação.

## ⚙️ Instalação e Requisitos

### Requisitos do Sistema
* **Sistema Operacional:** Windows 10 ou Windows 11 (64-bit)
* **Ambiente de Execução:** `.NET 6.0` ou superior
* **Privilégios:** Permissões de Administrador necessárias
* **Conexão:** Necessária apenas para baixar atualizações de definições

---

## 🚀 Como Usar

1. **Execute como Administrador:** Clique com o botão direito sobre o executável do programa e selecione `Executar como Administrador`.
2. **Análise:** Revise a lista de otimizações recomendadas geradas pelo diagnóstico inteligente.
3. **Aplicação:** Clique no botão **"Otimizar Tudo"** ou selecione manualmente os módulos que deseja aplicar.
4. **Finalização:** Aguarde o processo ser concluído e reinicie o computador para aplicar todas as alterações de forma segura.
